# 方案 2 跨阶段耦合复测

新版用配对试验验证了接近动作对冲击和时间的作用。带同一持续外力触桌的演示中，近台速度指令从 14 到 50 mm/s，首触峰值由 6.94 升至 25.20 N。两个回合都需要到外力结束后完成对中和撤手，完成用时均约 6.71 s。 [配对回放](../results/coupled_pilot/paired_demo.mp4) · [该配对的测量与配置](../results/coupled_pilot/demo_pair.json)

## 旧版复核

旧主矩阵按无扰、持续、随机扰动分组的首触峰值均值为 14.374、14.217、14.289 N。持续和随机扰动相对于相同台高、质量、控制器的无扰组，平均绝对差为 0.284、0.330 N。最后一次施扰最晚 1.898 s 结束，下降从 2.000 s 开始，触桌垂速中位数为 32.37 mm/s。

旧版最大峰值 20.357 N 在首次触桌的同一物理步出现。该回合峰值时参考高度 187.82 mm，全回合最低下降参考 176.60 mm。代码中的 85.00 mm 下界在这次接触过程没有激活。质量和首触速度决定了更大比例的峰值差异。 [旧版原始回合](../results/observer_pilot/runs.json)

## 本轮改动

| 设计项 | 实现 |
| --- | --- |
| 模型误差与载荷估计 | 实际臂质量及惯量同时偏 −4%、−2%、+2%、+4%，实际物块质心在三轴偏移，横向最多 8 mm、竖向最多 5 mm。标称模型独立。取消搬运前静止辨识，从 0.25 kg 先验开始，在搬运的低竖向速度、轻横向负载时更新估计。 |
| 补偿的选择 | 用在线估计质量计算重力前馈。标称质量前馈作为配对消融，二者的接触估计使用同一算法。 |
| 跨阶段施扰 | 力矢量模为 6–8 N，含 ±2.3 N 垂向分量。持续组安排于 1.46–4.80 s。随机组跨 2 s 并延伸到下降。有扰波形按仿真时钟产生，开夹后停止施力。 |
| 可控动作 | 两个刚度残差、近台速度（12–65 mm/s）、减速起点（参考高度差 28–132 mm）、夹爪指令（16–60）。42 维观测包含这三个执行中的命令状态。 |
| 触桌后的控制 | 估计接触时以估计 TCP 高度建立锚点，法向参考只在其 ±3 mm 内调整。重力前馈叠加平滑有界的 4 N 承托调节。 |
| 承托确认 | 施加至少 2.5 N 的向下指令后，要求估计承托在 3–5 N 之间、TCP 对中且相对锚点移动不超过 4.5 mm，法向速度在 5 mm/s 内，并保持 80 ms。承托消失或 TCP 继续移动时重新搜索。仿真真值用于离线确认开夹先后。 |

## 配对主矩阵

共 300 个主回合。20 个物理上下文覆盖 −40 至 +40 mm 的五档台高、0.18–0.34 kg 载荷和四档臂偏差。每个上下文跑三种扰动。三基线共用估计和释放逻辑。通过标准为 7.2 s 内完整放稳、开夹晚于真实触桌并且全程台面载荷峰值 ≤10 N。另有 44 个回合分别改变制动起点、夹爪或质量前馈。 [逐回合配置与结果](../results/coupled_pilot/runs.json)

| 控制与近台速度 | 通过 | 超时 | 已完成回合中位用时（s） |
| --- | ---: | ---: | ---: |
| 固定 360/300，22 mm/s | 18/60 | 28 | 6.193 |
| 规则分阶段，22 mm/s | 16/60 | 31 | 6.002 |
| 固定 520/300，16 mm/s | 17/60 | 25 | 6.046 |
| 固定 520/300，22 mm/s | 23/60 | 16 | 6.085 |
| 固定 520/300，50 mm/s | 2/60 | 4 | 5.348 |

时间中位数包括结束的冲击超限和越边回合。对固定 520/300 的慢、快指令，两边均触桌的 50 组配对中，快指令的全程力峰平均提高 9.25 N。两边均完成的 33 组中，快指令用时的配对差中位数为 −0.548 s。快慢组均触桌的子集用于比较峰值，完整通过率使用全部 60 个工况。 [分组数据](../results/coupled_pilot/summary.json)

**扰动对放置产生了可测影响。** 200/200 个有扰回合在 2 s 时仍受力，63 个在首次触桌时仍受力。与同工况无扰比较，持续组的首触峰值配对绝对差均值为 4.06 N（96 组），随机组为 5.08 N（95 组）。在触桌时持续施力的配对子集中，绝对差为 6.17 N（54 组）。

**估计量参与了控制，也暴露了误差。** 持续扰动下 20 个配对工况中，固定 520/300 使用在线质量前馈时搬运垂向 RMS 均值 4.15 mm，使用标称质量时 6.69 mm，统计窗口为搬运 0.3–2.0 s。全主矩阵在线质量估计 MAE 为 162 g，当前标量同时吸收臂模型的重力误差。113/300 个回合的首个估计接触发生在真实触桌前。加入承托确认后，300 个主回合及 44 个配对探针均无提前开夹。主回合 76 个通过，104 个超时，119 个以冲击超限结束，1 个越边。

**10 N 的可达性检验。** 对 +40 mm 台高的四个持续施扰上下文运行了 24 个有限刚度与夹爪动作探针。同一上下文的两种动作通过。演示分别用 14 和 50 mm/s 重放这个上下文的一个通过动作，其他四维动作完全相同。两次真实首触都承受 7.43 N 外力。低速回合全程峰值 9.52 N、6.708 s 通过，高速回合 25.20 N、6.712 s 冲击超限。该上下文在速度和夹爪相同时，法向刚度残差从 0 增到 0.85，搬运垂向 RMS 由 4.15 降至 3.22 mm，全程峰值也由 19.39 降至 9.52 N。刚度作用随工况而变，速度对照单独量测了冲击与用时。 [动作探针](../results/coupled_pilot/combined_action_probe.json)

## 复现与判断

Gymnasium 接口检查、真值扰动隔离检查和速度干预的搬运轨迹一致性检查通过。用 `coupled_approach: true` 的配置可以接入 SAC。此轮验证了动作的物理作用、可实现的力时间权衡和观测器弱点。113 个早期接触候选与载荷估计偏差仍需专门处理，学习能否优于调好的规则也需要独立训练对照。 [接口核验](../results/coupled_pilot/validation.json) · [训练接口联调](../results/coupled_pilot/training_smoke.json)
