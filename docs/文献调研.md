# 抗扰搬运与柔顺放置｜文献调研

**选题切口**　在一次机械臂搬放中，分别对悬空运输施加外力脉冲、对放置引入未知台面高度。保持参考路径和下降速度曲线一致，检验由反馈调节的水平与法向刚度能否改善搬运偏差与触桌冲击之间的权衡。

## 检索范围

截至 2026 年 11 月 19 日，使用出版社、会议论文集、arXiv、作者机构和项目页面。主要检索词包括 `robot variable impedance reinforcement learning`、`disturbance rejection object transport adaptive compliance`、`contact transition impact control`、`gentle stable robotic placement`、`force-aware residual controller bottle placement`。沿 VICES、接触转换和触觉放置三条线索补查近邻研究，并以 DOI 或 arXiv 编号去重。表中的结果只概括源论文对应的任务，数值阈值由本项目单独设定。

## 选题依据

搬运中需要关注扰动后的跟踪偏差和持物状态。低频小扰动下，增加水平刚度能缩小静态偏移。有限时长的脉冲还受阻尼、惯量和夹持摩擦影响，掉落率应独立统计。首次触桌时，触前速度、姿态和承托面几何与刚度共同影响力峰值。仿真记录这几个量，使同一回合的控制权衡可分解、可复测。 [搬运抗扰](https://ntrs.nasa.gov/citations/20240003652) · [触桌冲击](https://doi.org/10.20965/jrm.2012.p0028)

已有研究覆盖变阻抗、搬放和接触反馈，因此本课程项目的贡献限定为**自建有外力脉冲与台高不确定性的搬放场景，以及对固定分轴、规则分阶段、学习增益调节的受控比较**。水平与法向解耦可能已经足够，固定分轴对照须独立扫描两个刚度。在统一下降轨迹下，还须报告物块实际触前速度。 [VICES](https://arxiv.org/abs/1906.08880) · [柔顺释放](https://www.roboticsproceedings.org/rss08/p23.html) · [近期系统比较](https://rai-inst.com/resources/workshop/an-empirical-analysis-of-controller-selection-for-safe-execution-of-umi-style-policies/)
