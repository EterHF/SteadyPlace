# 抗扰搬运与柔顺放置｜方法与实验规划

## 要回答的问题

外力持续到接触时，机械臂能否把物块完整放在窄承托台上，同时控制触桌冲击与用时？各控制器的学习收益在相同参考轨迹和释放条件下比较。

## 自建仿真场景

| 要素 | 设计 |
| --- | --- |
| 机械臂与物体 | Franka Panda 7 轴臂，双指摩擦夹持 50 mm 立方体。标称质量 0.25 kg。物块以自由关节建模。 |
| 起点 | 用 IK 设置开夹对准的起始姿态。脚本闭夹、物理抬升 0.14 m，并检查双侧指尖接触。抬升后开始计时。 |
| 搬运 | 同高度横移 0.42 m，2.0 s 五次多项式轨迹。将有限时长的水平外力直接施加在物块质心。标准脉冲为 8 N、80 ms，开始于第 0.88 s，方位 25°。 |
| 接近 | 按名义高度执行预设下降曲线，参考速度约 0.125 m/s 平滑过渡至 0.035 m/s。改变目标台的实际高度和物块–台面摩擦。 |
| 承托与释放 | 仿真合成承托力低通后达到 0.65 N，物块与目标台保持接触且距目标中心 ≤38 mm，持续约 80 ms 后开夹。随后抬手 0.10 m。 |
| 成功 | 6.8 s 内，物块在目标台上，双指开到阈值且已脱离。水平误差 ≤25 mm、倾角 ≤7°、线速 ≤0.015 m/s、角速 ≤0.15 rad/s，连续满足 0.30 s，且抬手结束。 |
| 失败 | 双指接触持续丢失或物块离手过远、机械臂撞台，或超时。强外力掉落回合作为检测器测试。 |

## 预定方法

**底层笛卡尔阻抗，500 Hz。** 在固定末端朝向下，用 `F = K(x_ref−x) + D(v_ref−v)` 计算任务空间平移力，叠加姿态反馈力矩。关节命令 `τ = Jᵀw + τ_bias − 0.8 q̇`，其中 `w` 由平移力与姿态反馈力矩组成，`τ_bias` 为机械臂模型的重力及速度偏置补偿。`K = diag(k_xy, k_xy, k_z)`，`D_i = 2√(2 kg · k_i)` 为等效质量近似。力矩饱和、增益限幅、低通和变化率限制都实施在仿真内。变刚度的无源性需要独立验证。 [Hogan](https://doi.org/10.1115/1.3140702) · [Khatib](https://khatib.stanford.edu/publications/pdfs/Khatib_1987_RA.pdf) · [Ferraguti 等](https://doi.org/10.1109/ICRA.2013.6631284)

**规则调度加 SAC 增益残差，50 Hz。** 由搬运阶段、物块到名义桌面的间隙和低通承托力给出标称增益 `K₀`。策略读取关节状态、末端误差与速度、物块相对位置与速度、名义间隙、阶段、低通承托力及当前增益，输出 `a_xy, a_z ∈ [−1,1]`。两轴组目标增益用 `K₀ · exp(0.55a)` 调整，限在 140–730 N/m 和 30–620 N/m，随后平滑。参考轨迹、姿态、手指闭合指令和开夹守卫由共同控制逻辑给定。实际桌高、仿真实施的外力及质量参数不提供给策略。 [VICES](https://arxiv.org/abs/1906.08880) · [Johannink 等](https://arxiv.org/abs/1812.03201) · [SAC](https://proceedings.mlr.press/v80/haarnoja18b.html)

**奖励。** 每步计跟踪误差、时间和动作变化代价。在首触后 100 ms 内，计峰值增量和每步接触冲量，终点给予成功奖励或失败惩罚。逐物理步采样，避免以 50 Hz 记录遗漏首触高峰。

**反馈范围。** 低通承托力和物块位姿是仿真观测。离线冲击指标使用未滤波的目标台–物块接触力。物块接触合力和腕部 F/T 读数的物理含义不同，原型目标为仿真内对照。

## 已完成的基线评估

最初的 8 个脚本试跑全部放稳，强扰动负例触发掉落。SAC 已完成 64 个策略步和 48 次更新的接口联调，正式训练待开展。随后对三种脚本基线各测 144 回合。同一组质量、摩擦与力方向在各控制器、时程和台高中配对。 [原型试跑](../results/smoke/summary.json) · [联调记录](../results/integration/training.json) · [逐回合数据](../results/disturbance_benchmark/runs.json) · [分组汇总](../results/disturbance_benchmark/summary.json)

## 挑战任务与测试工况

将 50 mm 方块放到 64 × 64 mm 方形承托台上。物块与台面边线对齐时，理论上每侧只有 7 mm 余量。保留接触、开夹、撤手和稳定性条件，并要求稳定终态的物块水平投影完整落在台内。按带姿态的几何投影计算到台边的最小有符号边距，负值记为越边。原 380 × 340 mm 台面用于对照，两个台面分别测试标称高度和抬高 20 mm。

| 工况 | 水平外力 | 施力时程 |
| --- | ---: | --- |
| 无扰 | 0 N | 整回合 |
| 搬运期恒力 | 8 N | 搬运时刻 0.58–1.30 s |
| 接近时单次脉冲 | 8 N | 距台面 20 mm 起施力 80 ms |
| 接近时三次脉冲 | 8 N | 各 80 ms，距台面 20 mm 起，第 0、320、640 ms 施力 |
| 接近时持续恒力 | 4 或 8 N | 距台面 20 mm 起，最长 720 ms |

实际间隙按物块最低点与台顶的距离计算，只用于触发外力。接近阶段的外力最晚在开始开夹时停止，逐物理步记录实际冲量和首触时是否仍在受力。此次以峰值 8 N 配平搬运与接近阶段的施力设置，并用 4 N 恒力提供强度对照。各时程以及受开夹截断后的总冲量随实际持续时间变化。

三种脚本基线共用两种承托台、两档台高、六种施扰设置及八组新的质量、台面摩擦和施力方向。每种控制器 192 回合，总计 576 回合。统计原放稳率、完整放稳率、越边幅度和实际施扰覆盖，以及触桌后 100 ms 的峰值、冲量和完整放稳用时。 [逐回合配置与数据](../results/challenge_benchmark/runs.json) · [分组指标](../results/challenge_benchmark/summary.json)

## 待开展的实验

1. **抬高台面时的冲击与减速代价。** 固定水平刚度 520 N/m，交叉比较法向刚度档位 100 / 300 N/m 和原减速 / 提前减速。按名义桌高加 20 mm 前移减速起点，低速下限、下探下限和释放守卫一致。实际桌面偏差取 −20、0、+20 mm，使用无扰和搬运期单次脉冲检查结果。+20 mm 重点比较首触垂速、峰值力及冲量 P90，−20 mm 重点检查用时。法向阻尼随刚度按同一规则变化。
2. **接触后回中再释放。** 对比现有释放条件和基于几何边距的开夹条件。建立稳定承托后降低法向运动指令，保留横向回中，确认投影完整进入台内并稳定后开夹。用窄台无扰、搬运期恒力和接近期 4、8 N 恒力对照，量测等待时间、首触冲击、承托段力与完整放稳率。
3. **同参考轨迹下比较规则与 SAC。** 验证集调节固定分轴及规则基线，固定 520/300 N/m 纳入强对照。在选定减速曲线和共同释放判据下，比较规则和规则加二维残差。追加两种消融。力反馈消融屏蔽策略和标称增益调度的力输入，释放守卫保留相同承托反馈。阶段消融复用同一策略权重，分别在搬运和下降至开夹阶段启用或归零残差，共四种配置。

## 正式评测口径

- **训练**　质量 0.18–0.34 kg，台摩擦 0.45–0.80，台高偏差 −12 至 +12 mm。单次脉冲 0–10 N、60–100 ms，开始于 0.57–1.26 s，水平角度均匀采样。预设训练种子 11、22、33，每种子初始预算 30 万策略步。SAC 用两层各 128 单元的 MLP，学习率 `3e−4`、batch 256、buffer 20 万，热身 5000 步。
- **验证与测试**　64 个新验证工况选参数及检查点。再预先锁定独立测试表，使用新采样的质量、摩擦和角度。实验 1 的 3 个台高 × 2 个时程，各用 8 组参数，共 48 个工况。实验 2 的 2 个台高 × 4 个施扰配置，各用 8 组参数，共 64 个窄台工况。学习策略若用于窄台任务，正式训练采用对应的完整放稳终点，并在训练集中安排接触附近施扰。各组合按台高和施力时程报告。
- **轨迹**　报告搬运与下降至首触阶段的水平 RMS、峰值偏差。恢复用时从施力结束起计，目标水平误差 ≤5 mm 并保持 100 ms，到回合结束仍未达到的单独计数。
- **首触**　按 2 ms 物理步汇总首触后 100 ms 的竖直接触力峰值和冲量，同时报告接触前垂速。记录完整力窗口的分母，未触桌的力统计记缺失，回合仍计入成功率分母。
- **效率与权衡**　完成用时从抬升后算到放稳，仅在成功回合统计。比较同工况下用时、峰值 P90、冲量和轨迹偏差，报告三个种子及配对差值。将 5 个百分点作为正式比较的成功率容差，并检查峰值对接触数值设置的敏感性。

先跑法向刚度与减速对照，以及接触后回中与开夹对照。正式学习从单种子检查奖励、完整放稳、掉落与增益饱和开始，随后完成三个种子及消融。两个学习配置共约 180 万策略步，可按配置和种子并行。
